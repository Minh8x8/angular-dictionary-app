About this project

A lightweight English dictionary app that lets you look up meanings, pronunciations, synonyms, antonyms, and sources—fast.

Project overview

Type a word to see definitions grouped by part of speech, multiple phonetics with audio, and quick links via synonyms/antonyms. The page layout stays clean and accessible with native control flow and Angular Signals.

  • Cambridge‑like reading experience: word → phonetics → meanings → synonyms/antonyms → sources
  • Pronunciation pills with per‑phonetic audio
  • “Show more definitions” toggle when there are many results
  • Dark/light theme with PrimeNG Aura theme
